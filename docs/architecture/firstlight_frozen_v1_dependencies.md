# `firstlight` as a frozen historical v1 artifact — dependency record

**Status:** dependency record, prepared 2026-09-12 on instruction (Huayin): *"Treat firstlight as a
frozen historical v1 artifact. Before deleting tombstoned compiler code, document exactly which
shipped/public surfaces still depend on firstlight. Do not re-author firstlight merely to keep the
v1 compiler alive."*

**Verdict up front: freezing is safe and already true in substance. Deleting the tombstoned v1
compiler is NOT safe today**, because a gated website build depends on it — and the repo's own
caller-pinning guard cannot see that caller.

---

## 1. What firstlight is, and that it ships

Six files under `packages/columna-server/src/columna_server/governed/firstlight/`:
`governed-publication.json` (publication format major **1**), `manifold.cml`,
`lowering-receipt.json` (receipt format `"1.0"`, `mapping_provenance.mapping_format_version: "1"`),
`data.toml`, `warehouse/sales_lines.parquet`, `PROVENANCE.md`.

**They ship to PyPI users.** `pyproject.toml` declares
`[tool.hatch.build.targets.wheel] packages = ["src/columna_server"]`, and hatchling includes all
files under the package directory. Verified present in `dist/columna_server-0.12.0-py3-none-any.whl`.
Packaging is itself pinned by `test_firstlight_governed_fixture.py`.

Producer provenance: manifold-agent **v0.12.0 @ `df794a60…`** driven through columna-studio — a
commit that predates both the v2 authoring boundary and publication format v2. The re-producer
(`fixtures/firstlight/build.py`) refuses any other checkout.

## 2. Shipped code that reads it: none

No module under either package's `src/` contains the string `firstlight`. Two standing guards
actively forbid it — `test_no_shipped_code_knows_this_fixtures_name` walks both installed trees and
fails on any `.py` naming it, and `gen_firstlight.py` re-performs the same walk.

It is reached only through the generic governed path: `ManifoldStore` scans a user-supplied
directory, and `_load_one` classifies a unit as `ENTRY_GOVERNED` when the artifact, the
`SOURCE_MANIFOLD` ref, and both receipt digests agree. **Firstlight is shipped public data with a
documented access path and zero shipped code dependency.** `README.md` and
`packages/columna-server/README.md` both name the path, and both ship as PyPI long-description.

## 3. Public surfaces that depend on it

1. **The `/case` "governed standing" exhibit** and two body statements on `/columna`. Generated by
   `apps/website/scripts/gen_firstlight.py` into the committed `src/data/firstlight.generated.json`,
   which three Astro files `import` — so a missing JSON fails the site build outright.
2. **CI gates:** `generator-determinism` re-runs the generator and fails on non-reproducibility; the
   generator `die()`s rather than degrading. `site-build` and four node gates depend on the build.
   `website.yml` runs it in both the preview job and the production deploy job.
3. **`registry/sources/sources.json`** declares source `s-case` as generated by
   `gen_case.py + gen_firstlight.py`, enrolled in the `corpus-membership` gate.
4. **The public search index** carries 30 `/case` chunks scraped from the rendered exhibit.
5. **`registry.SUPPORTED_PUBLICATION_FORMAT_MAJOR = 1`** is the only reader that admits it, and
   firstlight is the **only shipped publication-format-major-1 artifact** in the repo.

## 4. Why the v1 compiler cannot be deleted today

`gen_firstlight.py` imports `compile_k0`, `parse_mapping`, `parse_publication` and re-runs
`compile_k0` to assert the shipped image reproduces byte-for-byte. It is a **hard build-time
dependency on both firstlight and the v1 compiler**, behind a gate.

Three further couplings:

- `columna_core/compiler/__init__.py` re-exports **eight** names from `inputs.py`. Deleting
  `inputs.py` breaks `import columna_core.compiler` — and therefore the **v2** tests, which import
  `compile_v2` and `realization` through that same package `__init__`.
- `compile_v2.py` imports `ClosedExecutionImage` **from** `compile.py`. Only the `compile_k0`
  function and the v1-specific bodies are separable; the module is not.
- `test_provisioner.py` (22 tests) is the only acceptance suite for the **shipped, public**
  `provision.provision_runtime_unit` API, and it can construct a valid publication/image/receipt
  triple only via `compile_k0`. Deleting the compiler deletes coverage for an API that stays in the
  wheel.

## 5. A hole in the freeze guard, found while documenting this

`test_the_v1_compiler_has_not_acquired_a_new_caller` enumerates an allow-list of nine paths and then
globs **`packages/**/*.py`** only. `apps/website/scripts/gen_firstlight.py` is a real `compile_k0`
caller, is not on the allow-list, and is invisible to the guard because it lives outside
`packages/`. The repo's freeze policy is therefore not enforced over the one caller that is
gated into the production deploy path.

**Smallest lawful remedy:** widen the glob to the repo root (excluding `.venv*`/`node_modules`) and
add `apps/website/scripts/gen_firstlight.py` to the allow-list explicitly, so the dependency is
declared rather than merely true. This is a two-line change to a test and is recorded here rather
than made, because it is outside the authorized correction set.

## 6. What freezing does and does not authorize

**Authorized by "treat as frozen":** stop re-authoring it; do not reproduce it under the successor
authoring system; do not extend the v1 compiler; keep the artifact bytes immutable.

**Not yet authorized, because a shipped or gated surface depends on it:** deleting the artifact from
the wheel (public-surface removal, and it would falsify two shipped READMEs), deleting `compile_k0`
or `inputs.py`, or raising `registry.SUPPORTED_PUBLICATION_FORMAT_MAJOR` to 2 — which would also
break six server test modules' inline major-1 publication dicts, independent of firstlight.

**The sequence that would make deletion safe**, if it is ever wanted: re-point `/case`'s exhibit at a
successor proof artifact → drop `gen_firstlight.py` from the generator set → re-home
`provision_runtime_unit`'s acceptance coverage → then delete the v1 compiler bodies and, separately,
decide whether the wheel keeps the historical artifact. None of that is required to freeze it.
