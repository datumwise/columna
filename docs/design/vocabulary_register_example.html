The register's illustrative example, kept on purpose: look at this before designing a new surface. Severity is ordinal (info < caution < critical) so it takes weight; mood is nominal (four kinds, no order) so it takes style. Both ink. Colour is reserved for verdicts.

Ratified ramp 2 / 4 / 7px — the 2px floor is deliberate: absence of a mark is itself meaningful here, so the lowest severity must stay visibly present.
