# The Platform Profile

**Frame-QL capabilities a conforming Platform implementation realizes, beyond Core.**

Platform **extends** Core:

```
Core Profile
    ↓ extended by
Platform Profile
```

That word is doing real work. A Platform implementation undertakes everything in the
[Core contract](core_profile.md), and then whatever this document adds on top. The table below is the
*additions* — never a standalone list, and never a replacement.

## Current additions: none

Platform adds no Frame-QL capability today. It realizes all of Core's Frame-QL and extends it by
nothing.

That is a statement, not an omission. "Platform adds nothing to Core" and "Platform realizes no
Frame-QL" are different claims, and only the first is true. Writing it down is the point: silence is
what let hand-maintained claims drift in the first place.

## What this document does not cover

Platform ships more than Frame-QL. The MCP tool surface, the natural-language agent, and the wire's
disclosure-level views are Platform product surfaces with their own contracts. They are not Frame-QL
capability realization, and they are not listed here merely because they ship alongside it.

This document answers exactly one question: which Frame-QL capabilities does a conforming Platform
implementation run that Core does not.
